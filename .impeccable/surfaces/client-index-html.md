## Direction contract

THESIS: WordWars owns "your word is a train already in motion" — refuses the static tile grid every word game defaults to (Wordle rows, Scrabble squares) for a live, directional, moving system where language itself travels a network.

OWN-WORLD: midnight-blue enamel ground, porcelain-white structural ink, four named line-accent colors (scarlet / cobalt / amber / lime) each owning one game mode or ELO tier, humanist transit-grotesk type at fixed label sizes, station-tick markers and route-line connectors replacing generic cards/borders as the primary structural device. JetBrains Mono retained only for numeric readouts (timer, ELO, scores) as a "departure board" digit face.

STORY: a first-time visitor understands within seconds that WordWars is a live, ranked word race — their rank reads as a line in motion, real matches scroll past as live "trains," and the primary action reads as boarding one.

FIRST VIEWPORT: a masthead-style nav (station-board header), hero headline over a live "service map" showing the visitor's rank-line and a moving live-match ticker styled as a train card, primary CTA styled as a platform/boarding action, prefix-as-interchange-station visual anchoring the hero demo.

FORM: Midnight Transit Network. Direction assigned via the decision round; won the challenger-fusion evaluation against the seed's assigned "newsprint puzzle page" (seed key a8862afe, mode persuade, assigned index 5) on both audience identification and product clarity — user confirmed after resolving a raised i18n concern (the diagram grammar is language-agnostic; station labels are translatable game-state strings, not real geography).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
